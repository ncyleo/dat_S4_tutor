# 中四設計與應用科技科自學 · 三欄

離線 HTML 自學：左課程目錄｜中教學＋練習｜右「定義 · 範例 · 引導提示」。課文版本 8（`lessons.json`），頁面快取參數 `?v=20261025m`。

## 本地開啟

用瀏覽器直接打開 `index.html`（課文已內嵌 `lessons-data.js`，圖片以相對路徑載入 `assets/`）。

## GitHub Pages

啟用後預期網址：<https://ncyleo.github.io/dat_S4_tutor/>

Leo 需自行開啟：**Settings → Pages → Deploy from a branch**，分支選 `main`，資料夾選 `/`（root）。此存放庫不會代為開啟 Pages。

## 檔案

- `index.html` / `app.js` — 三欄介面
- `lessons.json` / `lessons-data.js` — 課文與練習（請一併更新）
- `assets/` — SVG 示意與快龍 PNG
